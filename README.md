# Portfolio — Samy Rachad

Portfolio personnel : React 19, Vite, Tailwind v4, Three.js (avatar 3D interactif) et SAMI, une IA de démo (Ollama en local).

```bash
npm install
npm run dev     # développement (moniteur FPS)
npm run build   # build de production dans dist/
```

Déployé automatiquement sur GitHub Pages à chaque push sur `main` (`.github/workflows/deploy.yml`).
